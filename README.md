# SAAS-PYMES

Frontend (PWA) del agente de inventario para abarrotes de colonia en CDMX. Permite al dueño de la tienda registrar entradas, ventas, consultar stock y ver su ganancia estimada desde el celular — sin libreta, sin complicaciones.

MVP sin voz: React + Vite + TypeScript, pensado para instalarse como app ("Añadir a inicio") vía PWA.

Backend: [S-Pback](https://github.com/EraRamirez/S-Pback)

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- React Router
- vite-plugin-pwa
- Hosting: Cloudflare Pages
